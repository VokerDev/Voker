## Что это

Voker — **проводник по инструментам** пентеста и разведки для новичков. Не нужно
помнить десятки команд и флагов: идёшь по простому меню («что я хочу найти?»), а
Voker собирает команду, красиво показывает результат, объясняет каждый пункт и
сохраняет всё, что нашёл.

> **Важно:** Voker не хранит инструменты внутри себя. Он *оркестратор* — проверяет,
> что программа установлена, помогает поставить и запускает. Часть пунктов —
> встроенные функции на чистом Python, работают вообще без установки.

## ⚠️ Правовое предупреждение

Voker — для **обучения** и **легального** тестирования. Наличие инструмента в Kali
или в этом наборе НЕ делает его использование законным. Законно то, что ты
запускаешь **по своим системам или с письменного разрешения**. Проверять чужие
сети, сайты и Wi-Fi без разрешения — во многих странах уголовное преступление.
Учись на [HackTheBox](https://hackthebox.com), [TryHackMe](https://tryhackme.com)
и своих машинах. Ответственность за свои действия несёшь только ты.

## Требования

- Linux (в этой версии; Windows — в планах)
- Python 3.8+
- Доступ в интернет

## Установка и запуск

```bash
git clone https://github.com/<твой-ник>/voker.git
cd voker
python3 voker.py
```

Зависимостей нет — только стандартная библиотека Python.

Посмотреть все команды и что уже установлено:

```bash
python3 voker.py --list
```

## Как пользоваться

1. При первом запуске один раз прими правовое предупреждение.
2. Выбери категорию, затем действие.
3. Прочитай короткое объяснение, что произойдёт.
4. Если инструмент не установлен — Voker покажет команду установки.
5. Введи цель — результат придёт в аккуратной панели.

В главном меню: `[i]` — что установлено, `[r]` — результаты текущей сессии.

## Сохранение результатов

Каждая команда сохраняется в `~/.voker/results/`:

- `*.txt` — полный вывод с шапкой (команда, цель, время, код);
- `session_<время>.json` — сводка всей сессии (машиночитаемо);
- `*.pcap` — у перехвата трафика: открывается в **Wireshark**.

После каждой команды Voker показывает сводную табличку сессии прямо в терминале.

## Что внутри (55 команд, 6 категорий)

| Категория          | Что умеет                                                        |
|--------------------|-----------------------------------------------------------------|
| Разведка (OSINT)   | ник, почты/поддомены, DNS (dig/dnsrecon/dnsenum/fierce), WHOIS, гео по IP, EXIF/GPS, WAF, словарь со страницы |
| Сеть               | ping, живые хосты, arp-scan, порты/сервисы/ОС/vuln (nmap), masscan, traceroute, перехват в .pcap, свои порты |
| Веб                | заголовки, технологии, gobuster/dirb/ffuf, nikto, wpscan, nuclei, sqlmap |
| Wi-Fi              | список сетей рядом, аудит защищённости                           |
| Хеши, пароли, CTF  | hashid, john, strings, binwalk, steghide                        |
| Утилиты (встроенные)| Base64/HEX/URL/ROT13/Цезарь, хеши строки и файла, JWT-декодер, генератор паролей, CIDR-калькулятор, проверка порта, свой IP |

Внешние инструменты — сторонние проекты со своими лицензиями; Voker их только вызывает.
