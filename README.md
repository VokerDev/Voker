## Что это

Voker ведёт новичка за руку. Ты выбираешь простыми словами, что хочешь узнать
(«доступен ли хост», «какие порты открыты», «где находится этот IP»), а Voker:

1. проверяет, установлен ли нужный инструмент, и помогает поставить;
2. запускает его, показывая **живую анимацию и таймер** (видно, что не завис);
3. вместо непонятной простыни выводит **человеческий отчёт** — например
   «Порт 80 открыт — это веб-сайт»;
4. сохраняет **красивый HTML-отчёт**, который открывается в браузере.

> Voker не хранит инструменты внутри — он их вызывает. Это обёртка-проводник,
> а не замена знаниям.

## ⚠️ Правовое предупреждение

Voker — для **обучения** и **легального** тестирования. То, что инструмент есть
в Kali, **не делает его применение законным**. Законно то, что ты запускаешь по
своим системам или с письменного разрешения владельца. Проверять чужие сети,
сайты и Wi-Fi без разрешения — во многих странах уголовное преступление.
Тренируйся на [HackTheBox](https://hackthebox.com), [TryHackMe](https://tryhackme.com)
и своих машинах. Ответственность за свои действия несёшь только ты.

## Установка и запуск

```bash
git clone https://github.com/<твой-ник>/voker.git
cd voker
python3 voker.py
```

Зависимостей нет — только Python 3.8+ и Linux. Список инструментов:
`python3 voker.py --list`.

## Как это выглядит

- Живая анимация с таймером, пока команда работает; для некоторых сканов —
  настоящий прогресс-бар в процентах.
- После команды — короткий понятный отчёт на экране (✅ / ⚠️ / ❌).
- Полный технический вывод и красивый разбор сохраняются в `~/.voker/results/`
  (`.html` — открыть в браузере, `.txt` — сырой вывод).
- Пункт `[o]` в меню собирает **общий HTML-отчёт всей сессии** — удобно приложить
  к CTF-write-up или к заданию.

## Что внутри (26 инструментов, 6 категорий)

| Категория      | Что можно узнать                                                   |
|----------------|-------------------------------------------------------------------|
| Разведка       | владелец домена/IP, адреса и почта, поддомены, гео по IP, GPS из фото, ник в соцсетях |
| Сеть           | доступен ли хост, умный скан цели (мастер сам подберёт настройки), кто в сети, путь до сайта, запись трафика в .pcap |
| Веб            | как отвечает сайт, на чём сделан, скрытые страницы, базовая проверка, WordPress |
| Wi-Fi          | сети рядом, аудит своей сети                                       |
| Хеши и пароли  | тип хеша, подбор пароля (свои/CTF)                                 |
| Эксплуатация ⚠ | подбор пароля к сервису (hydra), тест SQL-инъекции (sqlmap) — только полигоны/CTF |

«Умный скан» — пример того, как Voker сам задаёт вопросы и подставляет нужные
флаги, чтобы новичку не пришлось помнить синтаксис.

## 🎯 Bug Bounty (пошаговый режим)

Пункт `[b]` в главном меню открывает рабочий процесс баг-баунти — инструменты
идут **по порядку использования**, с подписью, что делает каждый шаг:

1. **Задать scope** — сначала впиши разрешённые домены программы.
2. **subfinder** — найти все поддомены цели.
3. **httpx** — какие из них живые.
4. **gau** — забытые старые URL из веб-архива.
5. **ffuf** — скрытые пути и эндпоинты.
6. **nuclei** — прогнать по тысячам шаблонов уязвимостей.

Плюс `[p]` — **полный пайплайн одной командой**: поддомены → живые хосты →
уязвимости по одному домену, с единым отчётом. Это учит методике, а не тыканью
в разрозненные кнопки.

## 🧭 Сценарии — методология, а не набор кнопок

Настоящая работа — это конвейер: разведка → перечисление → уязвимости → доступ →
отчёт. Пункт `[c]` в меню запускает готовые сценарии, где инструменты идут по
порядку сами, а результаты сводятся в один отчёт:

- **Разведка сети** — живые хосты (nmap -sn) → порты и сервисы (nmap -sV).
- **Разведка сайта** — whois → dig → whatweb → скрытые страницы (gobuster).
- **OSINT по домену** — whois → dig → subfinder → theHarvester.

Плюс режим **Bug Bounty** (`[b]`) с пайплайном subfinder → httpx → nuclei и
полным алгоритмом в файле `METHODOLOGY_BUGBOUNTY.txt`.

## 📦 Инвентарь активов — данные связаны между шагами

Раньше каждая команда была сама по себе: nmap нашёл хосты — а дальше вводи IP
руками. Теперь находки (поддомены, живые хосты, IP, URL) копятся в общий инвентарь
(`[a]` в меню), и следующая команда **предлагает выбрать цель из найденного**, а
не заставляет печатать заново. Инвентарь сохраняется в `~/.voker/inventory.json`.

## Scope-guard (защита от выхода за рамки)

Пункт `[s]` в главном меню — список разрешённых доменов (scope). Пока scope задан,
любая активная команда против цели вне него **блокируется** с предупреждением.
В баг-баунти выход за scope — это бан из программы или хуже, поэтому scope стоит
задавать первым. Список хранится в `~/.voker/scope.txt`.

## Где легально тренировать активные инструменты

Активные инструменты (категория «Эксплуатация», а также сканы и Wi-Fi) можно
запускать только там, где это законно:

- [TryHackMe](https://tryhackme.com) — задания с нуля, много про веб и брутфорс.
- [Hack The Box](https://www.hackthebox.com) — учебные машины, где нужны nmap, hydra, sqlmap.
- [DVWA](https://github.com/digininja/DVWA) — намеренно уязвимый сайт, ставится локально.
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — бесплатно про веб-уязвимости.
- Свои собственные машины и виртуалки.

Категория «Эксплуатация» при первом входе за сессию просит подтвердить, что цель —
учебная площадка или своя система. Это не «разрешение на всё», а напоминание:
запуск против чужих систем без письменного согласия — уголовное преступление.
