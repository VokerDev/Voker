## Что это

Voker — **проводник по инструментам** пентеста и разведки для тех, кто только
начинает. Не нужно запоминать десятки команд и флагов: идёшь по простому меню
(«что я хочу найти?»), а Voker сам собирает правильную команду, красиво
показывает результат и объясняет, что делает каждый пункт.

> **Важно:** Voker не хранит инструменты внутри себя. Он *оркестратор* — проверяет,
> что программа установлена, помогает её поставить и запускает. Часть пунктов —
> встроенные функции на чистом Python, они работают вообще без установки.

## ⚠️ Правовое предупреждение

Voker создан для **обучения** и **легального** тестирования. Проверять чужие
сети, сайты и Wi-Fi без письменного разрешения владельца — во многих странах
**уголовное преступление**.

Используй только на: своих системах; системах, где есть письменное разрешение;
учебных площадках вроде [HackTheBox](https://hackthebox.com) и
[TryHackMe](https://tryhackme.com). Ответственность за свои действия несёшь только ты.

## Требования

- Linux (в этой версии; Windows — в планах)
- Python 3.8+
- Доступ в интернет

## Установка и запуск

```bash
git clone https://github.com/<твой-ник>/voker.git
cd voker
python3 voker.py
```

Зависимости ставить не нужно — только стандартная библиотека Python.

Посмотреть все команды и что уже установлено, не заходя в меню:

```bash
python3 voker.py --list
```

## Как пользоваться

1. При первом запуске один раз прими правовое предупреждение.
2. Выбери категорию, затем нужное действие.
3. Прочитай короткое объяснение, что произойдёт.
4. Если инструмент не установлен — Voker покажет команду для установки.
5. Введи цель (ник, домен, IP, файл) — и результат придёт в аккуратной панели.

Пункт `[i]` в главном меню показывает, какие инструменты уже установлены.

## Что внутри (25 команд, 6 категорий)

| Категория        | Что умеет                                                    |
|------------------|-------------------------------------------------------------|
| Разведка (OSINT) | ник в сети, почты/поддомены, WHOIS, DNS, гео по IP, EXIF/GPS |
| Сеть             | ping, живые хосты, порты, сервисы, ОС, traceroute            |
| Веб              | HTTP-заголовки, технологии сайта, скрытые папки, nikto, wpscan |
| Wi-Fi            | список сетей рядом, аудит защищённости                       |
| Хеши и пароли    | определение типа хеша, подбор по словарю                     |
| Утилиты          | Base64 туда-обратно, хеши строки (работают без установки)    |

Внешние инструменты — сторонние проекты со своими лицензиями; Voker их только вызывает.
