## Что это

Voker — это **проводник по инструментам** пентеста и разведки для тех, кто только
начинает. Он не заставляет тебя запоминать десятки команд и флагов: ты идёшь по
простому меню («что я хочу найти?»), а Voker сам собирает правильную команду и
запускает нужный инструмент.

> **Важно:** Voker не содержит инструменты внутри себя. Он *оркестратор* — проверяет,
> что программа (например `nmap`) установлена, помогает её поставить и запускает.
> Так весит мало, обновляется легко и учит тебя реальным инструментам, а не «магии».

## ⚠️ Правовое предупреждение

Voker создан для **обучения** и **легального** тестирования. Сканирование чужих
сетей, сайтов и Wi-Fi без письменного разрешения владельца — во многих странах
**уголовное преступление**.

Используй Voker только на:
- своих собственных системах;
- системах, где у тебя есть письменное разрешение;
- учебных площадках вроде [HackTheBox](https://hackthebox.com),
  [TryHackMe](https://tryhackme.com).

Всю ответственность за свои действия несёшь только ты.

## Требования

- Linux (в этой версии; Windows — в планах)
- Python 3.8+
- Доступ в интернет

## Установка и запуск

```bash
git clone https://github.com/<твой-ник>/voker.git
cd voker
python3 voker.py
```

Никаких зависимостей ставить не нужно — Voker написан на чистой стандартной
библиотеке Python.

Посмотреть все инструменты и что уже установлено, не заходя в меню:

```bash
python3 voker.py --list
```

## Как пользоваться

1. При первом запуске прими правовое предупреждение (один раз).
2. Выбери категорию — например `OSINT`.
3. Выбери, что хочешь сделать — например «Поиск по нику в соцсетях».
4. Если инструмент не установлен, Voker покажет команду для установки.
5. Введи цель (ник, домен, IP).
6. Для активных действий подтверди, что у тебя есть разрешение.
7. Voker покажет собранную команду и предложит её запустить.

## Какие инструменты оборачивает

| Категория        | Инструмент     | Назначение                          |
|------------------|----------------|-------------------------------------|
| OSINT            | `sherlock`     | Поиск ника на сотнях сайтов         |
| OSINT            | `theHarvester` | Почты и поддомены по домену         |
| OSINT            | `whois`        | Кому принадлежит домен/IP           |
| Сканирование сети| `nmap`         | Порты, сервисы, ОС                   |
| Веб-разведка     | `whatweb`      | Технологии сайта                    |
| Wi-Fi            | `wifite`       | Аудит беспроводных сетей            |

Все инструменты — сторонние проекты со своими лицензиями. Voker их только вызывает.
